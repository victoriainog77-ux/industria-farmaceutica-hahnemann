## Objetivo
Desarrollo y despliegue de un sitio web interactivo para la Industria Farmacéutica Hahnemann cumpliendo con HTML5 semántico, CSS3 Flexbox responsive, JavaScript dinámico, GitHub y Netlify.

## Cumplimiento de Requisitos Técnicos Mínimos

### 1. Estructura HTML (Semántica)
- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Catálogo dinámico en cuadrícula de tarjetas
- Formulario de contacto B2B funcional con validación

### 2. Estilos CSS
- Maquetación responsive con Flexbox (header, .grid, .stats, form)
- Sin frameworks - CSS puro
- Identidad visual farmacéutica: azul industrial #082a4d + celeste GMP #00d4ff
- Transiciones y hover

### 3. Funcionalidad JavaScript
- `Array de objetos` = `productos` (6 productos industriales con lote)
- `Renderizado dinámico` = `renderizar()` crea `article.card` en DOM
- `Carrito interactivo`: agregar, eliminar con `splice()`, cálculo total automático, contador
- Validación formulario HTML5 + JS (nombre min 3, email con @, mensaje min 10)

### 4. Publicación
- Repositorio: https://github.com/TU-USUARIO/industria-farmaceutica-hahnemann
- Sitio en producción: https://TU-SITIO.netlify.app
